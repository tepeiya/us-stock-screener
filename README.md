# 美股选股器 v2.0

> 五阶段漏斗选股系统：技术面 → 基本面 → 社交热度(30源) → 退场信号 → 13F持仓追踪

## 快速使用

### 方式一：直接打开网页
```bash
# 启动本地服务器
python3 -m http.server 8899 --directory /var/minis/workspace/
# 浏览器打开 http://localhost:8899/screener.html
```

### 方式二：安装到桌面（PWA）
在Chrome中打开 → 菜单 → "安装应用" / "添加到主屏幕"

### 方式三：通过Minis对话
在聊天框输入 "选股" 即可使用对话版选股器

## 功能特性

| Tab | 功能 | 说明 |
|:----|:----|:------|
| 📋 选股 | 综合评分排序 | 技术+基本面+热度+催化剂，含仓位建议 |
| 🛡️ 退场 | 止盈止损信号 | 止损价位 / RSI警戒 / 均线预警 |
| 📅 事件 | 财报+经济日历 | 候选股财报日 / FOMC / CPI / PPI |
| 🏛️ 13F | 大佬持仓追踪 | Buffett/Ackman/Dalio等增减持动向 |
| 🔥 热度 | 社交热度排行 | 30个KOL/基金大佬/资讯源的讨论热度 |
| 📈 板块 | 板块表现 | 11大板块近1月/1季/YTD表现 |

## 筛选框架（五阶段）

1. **基础门槛**: 股价>$10, 日均成交量>50万, Mid Cap+, 可期权
2. **技术面**: 均线多头排列(SMA20>50>200), RSI 40-70, 量价配合
3. **基本面**: PE合理, EPS正增长, ROE>10%, Short Float<10%
4. **社交热度**: 30个来源(基金大佬/策略师/KOL/资讯流), 权重评分
5. **催化剂+退场**: 财报日历/13F持仓/期权异动/止损止盈

## 项目结构

```
screener.html       → 主界面（6个Tab）
screener-style.css  → 深色主题样式
screener-data.js    → 股票数据 + 30个社交源 + 13F数据
manifest.json       → PWA配置
sw.js               → Service Worker（离线缓存）
icon-192.png        → 应用图标
icon-512.png        → 高清应用图标
```

## 自动更新机制

项目配置了 GitHub Actions + PWA Service Worker，每次推送新版本后：
1. 用户下次打开App自动检测更新
2. 静默下载新版本资源
3. 下次重载时自动应用更新
